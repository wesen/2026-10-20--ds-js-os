# cji: the compiler from *Compiling JavaScript, Incrementally*

This checkout contains the PicoCalc selection of the companion compiler. From this directory, run `NOSNAP=1 sh tools/rv32/nw-test.sh` to build and replay the included native-world fixtures and their C control. See the [import notes](../ttmp/2026/11/17/PICOCALC-CJI--cji-workspace-import-and-picocalc-integration-analysis/sources/README.md) for provenance and the scope of the upstream test suite.

Each chapter of the book has a tag here (`ch01`, `ch02`, ...). The code at a tag is the
code the chapter shows, and its tests pass.

```
git checkout ch13
make                         # builds slas, the SLIR assembler (chapter 2 on)
node run-tests.js            # every test program, checked at every stage
node run-tests.js --oracle   # also re-check the expected outputs against Node
node cji.js tests/dynamic/example.js --dump    # every IR (with liveness and the interference graph), then run
node cji.js tests/var/nested.js --emit    # the SLIR that slas assembles
./slas -v build/nested.slir               # SLJIT's own listing
./slas -g build/churn.slir                # the collector's statistics (chapter 6)
```

Layout:

| Path | What |
| --- | --- |
| `src/parse.js` | lexer and parser for the current chapter's JavaScript subset |
| `src/ast.js` | AST constructors and the S-expression printer |
| `src/interp.js` | one interpreter class per language, each extending the last |
| `src/grammar.js` | one grammar check per language |
| `src/compiler.js` | the pass list: name, function, and the interpreter for its output |
| `src/*.js` | one file per pass: `uniquify.js`, `rco.js`, `explicate.js`, `select.js`, ... |
| `src/slir.js` | SLIR: operands, instructions, the text printer, the machine-model interpreter |
| `src/liveness.js`, `src/allocate.js` | liveness, the interference graph, DSATUR colouring (chapter 3) |
| `src/typecheck.js`, `src/shrink.js` | the Int/Bool type checker; `&&` and `||` as `?:` (chapter 4) |
| `src/remove-jumps.js`, `src/layout.js` | merging blocks; ordering blocks so they fall through (chapter 4) |
| `src/uncover-get.js`, `src/dataflow.js` | reads of assigned variables; the worklist dataflow solver for liveness (chapter 5) |
| `src/check-bounds.js`, `src/expose-allocation.js`, `src/local-types.js` | index checks, allocation as code, the types of C variables (chapter 6) |
| `src/types.js`, `src/reveal-functions.js`, `src/defs.js` | type strings and type comments; function references; per-function passes (chapter 7) |
| `src/free.js`, `src/convert-assignments.js`, `src/convert-closures.js` | free variables and boxes; flat closures, static closures, known calls (chapter 8) |
| `src/dynamic.js`, `src/cast-insert.js` | dynamic values: NaN-boxing, their operations, the L_Dyn interpreters; casts (chapter 9) |
| `src/infer.js` | infer_types: the types nobody wrote, by abstract interpretation over a lattice of types (chapter 11) |
| `src/ranges.js`, `src/describe-types.js` | interval analysis: which Ints are exact; the inferred types as text, `.types` files (chapter 12) |
| `src/strings.js`, `src/slir-strings.js` | strings' methods and operators; the machine model's strings and records (chapter 13) |
| `src/math.js` | Math's functions: their types, the operators they become, their meaning (chapter 10) |
| `runtime/slas.c` | reads SLIR text, calls SLJIT, runs `main` |
| `runtime/runtime.c` | the C runtime: printing, run-time errors, the copying collector (chapter 6), strings (chapter 13) |
| `runtime/casemap.h` | Unicode's single-unit case mappings, generated by `tools/gen-casemap.mjs` (chapter 13) |
| `runtime/sljit/` | SLJIT, vendored (BSD-2-Clause, see its LICENSE) |
| `run-tests.js` | the harness: Node's output vs every interpreter and the compiled code |
| `tests/<family>/` | test programs; `.out` files hold Node's output |
| `tests/reject/` | programs outside the language; `.err` files hold the error each must produce |
| `*.trap` | next to a test: the run-time error the program must stop with (chapter 6) |
| `*.types` | next to a test: the types infer_types must choose (chapter 12) |
| `tests/spj/`, `tools/progress.mjs` | the real project's cases, and how many cji passes: `node tools/progress.mjs --cases` |
| `tools/mutate.mjs`, `tools/mutations/` | mutation testing: plausible bugs the tests must catch, per chapter (chapter 10 on) |
| `tools/types.mjs` | the types inference chose: `node tools/types.mjs file.js` |
| `tools/dump.mjs` | a program after any pass: `node tools/dump.mjs file.js select_instructions` |
| `ttmp/CJI-2-replace-spj/` | the plan for replacing SPJ, the diary, the task list |

Node 18 or later, no npm packages; a C compiler and make for `slas`.
