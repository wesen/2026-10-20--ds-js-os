# Port picocalc-os to the M5Stack PaperS3 (e-paper, touch, mquickjs)

## Structure

- **design/**: Design documents and architecture notes
- **reference/**: Reference documentation and API contracts
- **playbooks/**: Operational playbooks and procedures

- **sources/**: External sources and imported documents
- **various/**: Scratch or meeting notes, working notes

## Getting Started

Use docmgr commands to manage this workspace:

- Add documents: `docmgr doc add --ticket PAPERS3-PORT --doc-type design-doc --title "My Design"`
- Import sources: `docmgr import file --ticket PAPERS3-PORT --file /path/to/doc.md`
- Update metadata: `docmgr meta update --ticket PAPERS3-PORT --field Status --value review`
