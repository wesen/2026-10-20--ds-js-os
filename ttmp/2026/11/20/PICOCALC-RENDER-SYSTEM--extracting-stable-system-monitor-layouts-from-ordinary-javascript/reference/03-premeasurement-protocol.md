# Implementation protocol recorded before candidate measurements

The independent design adds a previous-frame diff (S1). The project's required retained baseline G uses the production complete JSON snapshot with exact equality suppression. S1 has a different recovery dependency. For a blind-prediction control we will separately cost a simple general path-diff codec including its initial full frame and one compulsory full restart frame. A remote idle restart must still have access to the complete retained representation. The experiment will not classify S1 as a project candidate.

The producer-side workload has 100 frames. The SDK title, battery and banner are compositor-owned; the fixture changes titles and a banner independently. A/A, each candidate and the holdout use identical inputs and deduplication. Beyond the independent criteria, release a limited automatic prototype if manual reduces the total enqueued SDK bytes by 30% or more against G and exact tree and action equality holds for every case. This is an exploratory host release gate. Automatic extraction keeps the same complete restartable envelope. Implementation will preserve JavaScript effects and object identity where they cannot be proved private. Report any resulting extra work. Compare System byte recovery against the manual saving; without a manual Keys arm its formal held-out 60% gate remains unqualified. One frozen extractor version faces Keys with zero allowed divergences.

Timing uses 30 paired blocks with rotating order; the frame is the unit for displayed byte statistics and the whole trace is the unit of timing replication. Use median paired ratios and a deterministic resampling interval for the p95 ratio, and price runtime in source UTF-8, gzip-9 and serialized QuickJS bytecode where available. The latter can estimate a packaged component without claiming installed firmware size. A fully materializing template is expected to reconstruct the same logical tree as G. P6 remains an independent prediction it can fail.
