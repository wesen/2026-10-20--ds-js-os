# Scientific review of the independent hardware manuscript

The first manuscript has the correct physical microseconds and percentages. Please rewrite the research article and your own chronological diary with the following corrections. Use a short example such as two distinct lexical scopes both using the spelling `i`, and explain why a stored token cannot share the parser's mutable current object. These details help a new intern understand what was actually built.

- The device cold measurement produces a **native linked RV32 Editor executable** from typed source inside QuickJS. The compiler itself runs under QuickJS. Wasm is the second target tested on the host.
- The measured module byte count includes a fixed reserved code slot. Equal physical sizes are expected and cannot establish identical contents. The host compared actual bytes in nine app/target-mode combinations across Files, Agenda and Editor, with negative-input comparisons reported separately. Avoid any universal claim about all programs.
- The cursor oracle counted 9,470 bounded/seek **observations**, and separately 3,072 randomized traces, plus 73 compiler inputs. Eight explicit sample sources and 271 randomized sample sources yielded indices. These are different units. The producer compared **129,572 token records from 2,519 accepted sources**, saw **twelve deliberately unsupported/ambiguous source inputs** and **three separate deliberately forced allocation failures**. There is no representative decline-rate estimate. These were constructed correctness tests. Avoid attaching the 12 or 3 refusals to a denominator or suggesting they measure real-world prevalence.
- 428,588 bytes = 418.54 KiB and 429,484 bytes = 419.42 KiB. Bytes and KiB differ by a factor of 1024. The manual-to-async difference is 763,132 bytes or 745.25 KiB. The reuse arm leaves 1,508,044 bytes, approximately 1.44 MiB of headroom. The peak figures describe temporary plus persistent compiler allocations. They cannot establish retained heap after compilation.
- The token-reuse arm borrows one mutable current-token object per eligible cursor at two non-retaining parser sites. This reuses storage across successive occurrences regardless of whether their spellings match. The external lexer API and async machinery that saves multiple tokens still receive independent objects. Token reuse and spelling interning are distinct operations.
- The manual control has both a different compiler and a different source. It sets the qualification threshold. Absolute savings from the two experimental arms are measured against the async control. The 84.44 ms gap is the difference from that target, not a separately observable compiler pass.
- In your diary give the correct numbers and units again if you use them. Add the concrete failed draft findings, how you corrected them, and review instructions. Discuss only predictions you can distinguish from measurements. Do not imply that the author touched the board.
