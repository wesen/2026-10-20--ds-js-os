Study contract for certificates of static native stack demand in ordinary generated RV32 code.

Emit a typed method name, start/extent, aligned local frame bytes, and named direct call sites (including SDK import names). Independent consumer decodes final linked bytes. It recognizes the release backend's 32-bit RV32 instruction subset, canonical fixed frame entry and exit, direct local branch and named/internal/import calls, audited local stack memory accesses and canonical return-address save/restore. Unknown opcodes, compressed words, unsupported SP/return patterns, foreign control transfers, out-of-range frame slots, dynamic frames and cycles fail closed. Statically unreachable bytes are still decoded; the conservative call graph may include unreachable calls. Named imported trampoline use is explicit; zero SDK additional depth is never presumed to mean complete native stack.

Compare machine-derived frames, call sites and targets with emitted claims. For a closed DAG compute peak(entry)=frame(entry)+max(peak(callee),0); siblings enter sequentially, never sum siblings. For SDK paths report maximum typed-byte prefix and named unresolved external terms. A total is conditional on certified bounds for every external entry, a nonreentrant SDK contract and no extra runtime interrupt/task/callback frames. Prove frame transitions for the restricted shape; scope excludes corrupt data pointers and native memory safety. Test chains, siblings, locals, branches and real Editor/Chess through final linked slot. Deliberately inaccurate claims or unsupported instruction fixtures must be rejected. Collect coverage and host certificate overhead; optional P4 cost. Freeze before receiving independent fixture.
