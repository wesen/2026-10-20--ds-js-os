Policy for trusted in-memory native fragments, release Typed compiler (streamed path).

The ordinary parser scans and validates every declaration, the async frontend regenerates its entire layout, and the complete linker and global cycle check run every time. Cache identity pins source-language implementation, compiler, backend/options, and target; no file cache in this study. Backend source has no literal pool; short/long constants are emitted in the fragment, and an alternate pool backend is unsupported. Do not reuse across those backend identities.

Require exact body including braces; own signature/parameter binding spellings; async generated-prefix/start-field mapping. Record the emitter's actual read set: call name, parameter/result/awaitability; record existence; concrete field type and byte offset on each used field; enum existence and complete consulted enum member table (including exhaustiveness); distinct-membership positives and negatives. Revalidate each recorded observation in the current declarative environment. Unknown map methods stop the candidate, never silently erase dependencies. Retain symbolic names for call targets and graph edges, relative positions for local labels; rebind all to current indices/addresses, reject or rebuild missing targets. A failed build never publishes its new root. Any unsupported feature requiring a broader dependency descriptor is a miss or explicit rejection. Measure current Editor and Chess local, signature, layout edits against both stock and whole-descriptor cache; pair byte-identical whole ELF and diagnostics. Assess P4 wall time returning the edited ELF. Declare results as measured comparisons, not an arbitrary-edit proof.
