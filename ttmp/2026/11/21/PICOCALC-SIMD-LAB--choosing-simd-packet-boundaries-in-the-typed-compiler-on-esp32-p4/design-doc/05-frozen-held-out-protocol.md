# Frozen prediction protocol

Use the source of a single loop that accumulates squared positive interval penetration from an array of distances. The loop's input, threshold, consumer and application differ from the ray fixtures. The same affine checked subtraction and guard make it intentionally a within-family transfer test. This is a collision-response cost proxy, not a complete rigid-body collision detector. Use constant trip variants 8 and 96 and a dynamic bound tested at 3, 17 and 96. Test at least two hit densities. Each compile-time selection sees only the candidate loop tape, constant trip count where provable and number of written streams. It cannot see measured hit rates or device results. Unknown dynamic bounds use the frozen prior of 32. A per-loop proof failure routes to the ordinary backend. Alignment and capacity guards remain. The cost function in scripts/director/selector.js fixes the plan ranking before the new benchmarks. The weights are structural hypotheses, not measured cycles. No new all-miss recipe may enter this three-arm test post hoc.

The independent device assay runs all three legal implementations of each variant, keeps the result and inputs identical and rotates the order over all six permutations. Directly compare each selected time with the fastest observed median for that same workload and report (selected / best - 1) as percent regret. The chosen raw image must match that arm byte for byte. Report cold compilation with each mode from an independent VM and a separate execution benchmark. Running simultaneous independent candidates on one board would confound the measurements, so the lab has one board operator. Keep adverse results. An all-PIE winner proves little about where to switch; compare frozen selection with the constant PIE and scalar policies.
