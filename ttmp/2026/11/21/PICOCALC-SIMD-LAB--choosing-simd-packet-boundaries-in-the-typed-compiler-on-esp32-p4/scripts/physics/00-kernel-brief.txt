Return code now by writing physics.S and physics.typed into this workspace. An independent engineer tests the files. The caller handles allocation, bounds, schedules and reporting.
1. Particle x,v signed 16-bit Q8.8 cells. x=signed saturation of x+v; v unchanged. Assembly symbols particle_aos_scalar, particle_soa_scalar, particle_aos_pie, particle_soa_pie: void f(int16_t *data,unsigned n). AoS interleaves x,v; SoA places n x cells before n v cells. Handle n from zero through 128, valid naturally aligned data, full groups and tails. For SoA when planes unaligned choose aligned stack-bounce or scalar with clear guard. For AoS gather into aligned stack lanes then packed signed saturating addition, scatter. Use only vector q0,q1,q2 because of RTOS context save. Standard callee-saved ABI, .option norvc. A manually optimized scalar comparison should have no loop spills.
2. Ordered body pairs (u16 indices). A,B signed16 old body velocity; d=floor((B-A)/2) in widened i32; assign A+d, B-d in original pair order. Native symbols contact_scalar,contact_pie: void f(int16_t *velocity,uint16_t *pairs,unsigned pairCount). PIE input lists have no repeated body within the list. Pack A,B,d into aligned stack lanes and use vadd.s16 and vsub.s16. d fits i16 including -32768, and both output values are within range by construction. Same semantics for scalar tails.
3. physics.typed exports particleAoS(b:buffer,n:i32), particleSoA(b:buffer,n:i32), contacts(b:buffer,pairs:buffer,m:i32); all take valid arrays expressed in UTF16 buffer cells, return n or m. Explicitly sign extend reads and preserve checked writes, saturate particles, use signed right shift for division by two in contacts. Keep code self-contained.
