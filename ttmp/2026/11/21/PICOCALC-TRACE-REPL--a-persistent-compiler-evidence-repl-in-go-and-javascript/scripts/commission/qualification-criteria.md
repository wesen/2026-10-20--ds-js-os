# Product qualification handoff to Opus xhigh

A compiler researcher must be able to reproduce a phenomenon and to distinguish a candidate experiment from validation. The following checks were selected before the blind runs. The lab director will return any failed public calls and the corresponding artifact evidence for repair.

1. Reproduce the original 26 example modules through distinct HTTP evaluations in one session. Separate a known measurement from an explicit unsupported capability, an invalid call and a display-size limit. Do not improve the score by substituting a different scientific question.
2. The gateway redacts the private native bridge, leaves a warm named binding intact between calls, and uses the immutable archive verified on startup. A copied result must not mutate historical evidence.
3. Keep pass evidence inside its real print. The directory gives the interval up to the next dump header. LLVM sometimes appends the *next* pass announcement to this range. A text excerpt must not attribute the trailing pass-manager announcement to the earlier transformation.
4. For every intervention, record unit, baseline, denominator, match conditions and a way to recover the inputs. The two distinct virtual-register rewriter ordinals, neighboring 73/74 LLVM states and checked LSR on/off executions exercise all of these rules.
5. The independent physical study's image digests and source identity belong to that study. Identically named emulator treatments are insufficient for a per-PC join. Check presence before any P4 timing claim.
6. Inspect scientific false positives in addition to syntax and convenience failures. Help may show valid calls. If it gives away a task answer, label the affected item as assisted. Preserve each participant's real errors.
7. For a candidate fix, ask a fresh investigator to carry out the original goal in a new session. Report measured change and uncertainty. A one-run improvement in tool calls does not establish a model-wide improvement.

The product owner should keep a detailed investigation diary. The director keeps the acceptance ledger and performs final remote publication. The study authors and user participants have their own records.
