                                                                          accepted ELF with a clean build. The field change is especially valuable: on the host it rebuilt 77 functions, and 70 produced
                                                                          identical linked instructions.

                                                                 removed and the save/restore instructions introduced. Judge the result on physical guest cycles, cold compile time and peak heap. The

  ─────  ─────────────────────────────────────────────────────  ────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
   6      Prove bounds through more than one guard. Scope E8.    Give the compiler the real Editor case 0 <= i, i < end, and end <= text.length. Can it prove text[i] safe before its fixed search budget
                                                                 runs out? Compare existing checks, direct guard recognition and bounded proof search. Exercise reassignment and control-flow joins. Count
                                                                 checks executed during the 64 KiB preview, alongside emitted bytes and compile cost.
  ─────  ─────────────────────────────────────────────────────  ────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
   7      Predict which functions deserve analysis.              The previous selector saved 720 words or zero when we changed only declaration order. Compare source-order selection, a cheap literal-only
                                                                 rule, and a predictor of benefit per unit of analysis work. Freeze each policy before testing it on unseen programs and reordered variants
                                                                 where the budget actually binds. This is the strongest candidate for an original research result.
  ─────  ─────────────────────────────────────────────────────  ────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
   8      Compile one real await end to end. Scope G.            Take Editor Open from typed source through suspension and native resumption. Determine which locals must survive the wait, generate the
                                                                 continuation, then compare it with the hand-written implementation on success, failure and cancellation. Record saved fields, frame bytes,
                                                                 code size and compile time. One complete workflow is a substantial result; Find supplies a later independent test.
