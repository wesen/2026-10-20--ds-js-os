### Measurement decisions and findings

The capture parser joins tags to the intervening streamed marker, successful compilation, byte length and digest. It checks each lane has equal representation in every cold compile position per boot. The physical guest driver rotates actual execution, then prints a lane-sorted duration array. Reading printed guest order as execution order would give an incorrect confounding diagnosis.

The retained-payload getter reads actual map values on the independent host staging copy. It sums the source lengths already referenced by retained fragments without changing admission. In a buffer of length 199, the first valid store is observable before the second traps. A stale layout traps earlier. The compiler’s own ELF parity tests alone could not distinguish these particular behaviors.
