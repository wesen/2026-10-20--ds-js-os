- **`step` (s2).** §8.5: "on a match, call the corresponding `step`"; elsewhere `start` and `resume`.

Nothing says the listing would be rejected, and the §8.5 outline drops `text`, so "the remedy" is never shown.
- **"each callee has exactly one caller position recorded in the caller's `state`" (3).** The frame table's `state` has no value meaning "waiting for my callee"; no nested `await` is shown. A helper awaited from two places in one task has two caller positions (s1).
