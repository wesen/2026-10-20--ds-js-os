## 1. Errors and inconsistencies in the article

- **Termination has an unstated premise (s2, s3).** §7.5: "Because no unbounded execution can avoid passing a back-edge, the program cannot run indefinitely." True only if every reactor function returns in bounded time; §7.4 says only "C code with no recursion". With "Subtracting 1", reactor calls in a loop are unbilled.
- **Compile-time against run-time charge (s2; s3 partly).** §7.5 fixes one amount per back-edge ("For an `if` it takes the longer branch"), yet a reactor call costs "its worst case for the given arguments", known only at run time. Where is that subtracted, and which branch is then "longer"? Also unsaid: whether "greatest straight-line cost" includes the callee's own callees (s3).
- **Masking (s3).** "`address = base + (address AND mask)`": mask undefined (size − 1); `address` names both input and result.
- **Grader's check.** The verifier table's "the summed frame sizes fit the world's stack" contradicts §7.4's frame plus largest callee need. "Every branch and jump target is a 4-byte-aligned address inside the slot" allows jumping past a bounds check or mask, or into another function.

Not confirmed: s2's "table that is never printed"; it follows the sentence.
