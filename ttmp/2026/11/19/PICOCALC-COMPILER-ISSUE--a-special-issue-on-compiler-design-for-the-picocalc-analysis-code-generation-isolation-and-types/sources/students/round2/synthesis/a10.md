- **What is generated, §10.2 against §10.8 (2/3).** §10.2 generates "the compiler's table, the trampolines and the C prototypes" and says only "the order in the first two files" matters. The figure's third file is "the C implementation of each function"; §10.8 says "three files that must agree in order. One interface description should generate all three".
