## 1. Errors and inconsistencies in the article

- **Bounds-check count, §9.4 (2/3).** "about four: load the length, compare and branch, and the trap itself" names three things. The hand-written "two" is those three less the load, so the text's own items give three.
- **"any call", §9.4 (2/3).** The fact holds "until `i` or `s` is assigned or any call is made", yet the protected access `s.charCodeAt(i)` is written as a call. The fact dies at the access it justifies.
- **Criterion 1 against §9.7 (2/3).** §9.4: "would need knowledge of the called function, which the first criterion rules out". §9.1 allows "the declarations it mentions", and in §9.7 "the compiler knows every callee's effect when it reaches a call".
- **Forward calls against §9.7 (1/3).** §9.7 needs "typed functions are defined before they are called"; §9.9 proposes "the ability to call a function defined later in the file" and mentions only the stack bound.
- **"the generated code is the same as today's", §9.2 (1/3; partly confirmed).** True for `FindPhase`; 14 and 15 need explicit member values, which are not mentioned.
